# Code of Conduct

## 🤝 Our Commitment

We want M.O.N.I.C.A. to be a welcoming, respectful, and collaborative open-source project.

Everyone participating in the project is expected to treat other contributors with respect.

---

## ✅ Expected Behavior

Examples of positive behavior include:

* Being respectful and constructive
* Welcoming new contributors
* Giving useful technical feedback
* Accepting different opinions
* Focusing on the technical problem
* Helping others learn
* Giving credit where appropriate
* Keeping discussions professional

---

## ❌ Unacceptable Behavior

The following behavior is not acceptable:

* Harassment
* Personal attacks
* Hate speech
* Discrimination
* Threats
* Deliberate intimidation
* Sexual harassment
* Publishing someone's private information
* Malicious behavior toward contributors
* Trolling or intentionally disruptive behavior

---

## 💻 Technical Disagreements

Technical disagreements are normal in open-source development.

Please focus discussions on:

* Implementation
* Architecture
* Performance
* Security implications
* Maintainability
* Project requirements

Do not turn technical disagreements into personal arguments.

---

## 🔐 Security and Privacy

Never publish:

* Telegram session strings
* API keys
* Passwords
* Tokens
* Private messages
* Personal information
* Private logs

Security issues should be reported according to [`SECURITY.md`](SECURITY.md).

---

## 🛡️ Enforcement

Project maintainers may remove, edit, close, or reject content or contributions that violate this Code of Conduct.

Repeated or serious violations may result in temporary or permanent removal from project participation.

---

## 🌐 Scope

This Code of Conduct applies to:

* Project repositories
* Issues
* Pull Requests
* Discussions
* Official project spaces
* Other project-related communication channels

---

## 💬 Questions

If you are unsure whether something is appropriate, choose the respectful and constructive approach.

Thank you for helping keep the M.O.N.I.C.A. community welcoming and productive.
